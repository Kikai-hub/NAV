Этот файл содержит шаги, которые нужно выполнить в Unity Editor вручную.
Я (Claude) не имею доступа к редактору Unity и не могу выполнить их сам.

Актуально на: 2026-08-21.
Что реализовано в коде: система взаимодействия (raycast-interaction) —
`IInteractable`, `PlayerInteractor`, `DebugInteractable`
(`Assets/NAV/Scripts/Gameplay/Interaction/`).

------------------------------------------------------------------------

## Шаг 1. Открыть проект и дать Unity перегенерировать .meta-файлы

Просто открой проект в Unity Editor (версия 6000.5.2f1). Unity сама
создаст `.meta`-файлы для новых скриптов:

-   `IInteractable.cs`
-   `PlayerInteractor.cs`
-   `DebugInteractable.cs`

Дождись окончания компиляции (внизу справа исчезнет крутящийся значок).
Если в консоли есть ошибки компиляции — не переходи к следующему шагу,
пришли мне текст ошибки.

------------------------------------------------------------------------

## Шаг 2. Добавить компонент PlayerInteractor на объект Player

1.  В окне **Hierarchy** открой сцену `Assets/Scenes/SampleScene.unity`
    (если она ещё не открыта).
2.  Выдели объект **Player** в Hierarchy.
3.  В Inspector нажми **Add Component**.
4.  Найди и добавь `PlayerInteractor` (namespace `NAV.Gameplay.Interaction`).
5.  У добавленного компонента `PlayerInteractor` заполни поля:
    -   **Input Handler** — перетащи туда же объект **Player** (в нём уже
        есть компонент `PlayerInputHandler`).
    -   **Camera Transform** — перетащи объект **Main Camera**.
    -   **Interact Range** — можно оставить по умолчанию `3`.
    -   **Interactable Layers** — можно оставить `Everything` (по
        умолчанию).

------------------------------------------------------------------------

## Шаг 3. Подключить PlayerInteractor к отладочному HUD

1.  На объекте **Player** найди компонент `PlayerDebugHud`.
2.  В поле **Interactor** перетащи тот же объект **Player** (тот, на
    который в Шаге 2 добавлен `PlayerInteractor`).

Это добавит в HUD (F1 — показать/скрыть) строку `Interact: ...`,
показывающую подсказку текущего объекта, на который смотрит камера.

------------------------------------------------------------------------

## Шаг 4. Создать тестовый объект для проверки (DebugInteractable)

1.  В Hierarchy: правой кнопкой → **3D Object → Cube**.
2.  Переименуй куб в `TestInteractable`.
3.  Поставь его в паре метров перед точкой старта игрока, на уровне
    земли (например, `Position: (3, 0.5, 3)`), чтобы в него можно было
    посмотреть камерой.
4.  Убедись, что на кубе есть компонент **Box Collider** (Unity
    добавляет его автоматически при создании Cube — просто проверь, что
    он не был случайно удалён).
5.  Add Component → добавь `DebugInteractable` (namespace
    `NAV.Gameplay.Interaction`).
6.  Поле **Prompt** можно оставить как `Interact` или написать что-то
    своё, например `Нажми E`.

------------------------------------------------------------------------

## Шаг 5. Проверка (playtest)

1.  Нажми **Play**.
2.  Наведи камеру (мышью) на куб `TestInteractable`, подойди на
    расстояние взаимодействия (по умолчанию 3 метра).
3.  В HUD (левый верхний угол, если скрыт — нажми F1) должна появиться
    строка `Interact: Interact` (или твой текст из Prompt).
4.  Зажми клавишу **E** (действие Interact в проекте настроено как
    "Hold" — то есть нужно **удерживать**, а не просто нажать один раз;
    примерно 0.4 секунды).
5.  Ожидаемый результат:
    -   куб должен поменять цвет (по умолчанию — на зелёный);
    -   в окне **Console** должно появиться сообщение вида
        `TestInteractable was interacted with by Player.`
6.  Отойди от куба или отверни камеру — строка `Interact: ...` в HUD
    должна пропасть (замениться на `Interact: -`).
7.  Ещё раз удержи E, глядя на куб — цвет должен переключиться обратно.

Если что-то из этого не работает — опиши мне, что именно (что видно в
HUD, что в Console, на каком шаге не совпало с ожиданием), и я
разберусь.

-   Действие **Interact** уже было в `InputSystem_Actions.inputactions`
    (клавиша **E**, режим "Hold") — я не создавал новый Input Action,

    Input Actions менять не нужно.

    тестовый объект только для проверки. Его можно оставить в сцене
    до тех пор, пока не появятся настоящие интерактивные объекты
    (предметы, ресурсные узлы, сундуки — это будущие фазы
