## Шаг 6. Новое: основа системы предметов (Items Foundation)

Пока тебя не было, я добавил самое начало системы предметов (Фаза 2 из

### 7.1. Добавить PlayerInventory на объект Player

2.  Add Component → добавь `PlayerInventory`

### 7.2. Подключить Inventory к HUD (необязательно, но полезно для проверки)

2.  В поле **Inventory** перетащи объект **Player** (тот же, где добавлен

### 7.3. Создать тестовый объект для подбора

1.  В Hierarchy: правой кнопкой → **3D Object → Sphere** (чтобы визуально
    отличался от куба взаимодействия из Шага 4).
2.  Переименуй в `TestPickup_Wood`.
3.  Поставь рядом с игроком (например, `Position: (-3, 0.5, 3)`).
4.  Проверь, что есть **Sphere Collider** (добавляется автоматически).
5.  Add Component → добавь `ItemPickup`
    (namespace `NAV.Gameplay.Items`).
6.  В поле **Definition** перетащи ассет
    `Assets/NAV/ScriptableObjects/Items/Wood.asset`.
7.  В поле **Quantity** укажи, например, `5`.

### 7.4. Проверка

1.  Нажми **Play**.
2.  Подойди к сфере `TestPickup_Wood`, наведи на неё камеру.
3.  В HUD должна появиться строка `Interact: Pick up Wood`.
4.  Зажми **E** (удержание, как и раньше).
5.  Ожидаемый результат:
    -   сфера должна исчезнуть (если весь стак поместился в инвентарь);
    -   в Console — сообщение вида
        `Player picked up 5x Wood (now has 5).`;
    -   в HUD строка `Inventory: 1/20 slots used` (один слот занят
        деревом).
6.  Если инвентарь окажется полон (не в этом тесте, а в будущем) —
    сфера должна остаться на месте, а в Console появится сообщение
    `... inventory is full; could not pick up ...`.

Как и с кубом — `TestPickup_Wood` и `Wood.asset` можно оставить как
временный тестовый контент до появления настоящей системы добычи

5.  Нажми **I** ещё раз — панель должна закрыться, курсор снова

## Шаг 9. Новое: Gathering, инкремент 1 (ResourceNode)

Первый кусок Gathering (Фаза 3 из `DEVELOPMENT_ROADMAP_v0.1.md`) — узел
ресурса в мире, который можно "бить" несколько раз (E, как обычно),
пока он не даст ресурсы и не исчезнет. Я добавил:

-   `Assets/NAV/Scripts/Gameplay/Items/ResourceNodeDefinition.cs` —
    ScriptableObject-данные узла: какой предмет даёт, сколько за один
    удар, сколько ударов до истощения.
-   `Assets/NAV/Scripts/Gameplay/Items/ResourceNode.cs` — сам узел
    (реализует `IInteractable`, как `ItemPickup`). Каждый Interact() —
    один "удар": добавляет предметы в `PlayerInventory`, уменьшает
    счётчик оставшихся ударов, слегка уменьшает объект в размере
    (временная визуальная обратная связь) и при истощении уничтожает
    объект.

**Сознательно не сделано в этом инкременте** (по роадмапу это отдельные
пункты Gathering, не забытые): требование инструмента (топор/кирка —
пока нет системы Equipment), респавн/сохранение узлов (нужна система
Save), нормальные VFX/звук добычи.

### 9.1. Дать Unity перекомпилировать

Перейди в Unity, дождись компиляции, проверь Console на отсутствие
ошибок.

### 9.2. Создать тестовый ResourceNodeDefinition

1.  В окне **Project** перейди в `Assets/NAV/ScriptableObjects/Items/`.
2.  Правой кнопкой → **Create → NAV → Items → Resource Node Definition**.
3.  Назови ассет `TreeWoodNode`.
4.  В Inspector заполни:
    -   **Display Name** — `Tree` (необязательно, если оставить пустым —

    -   **Drop Item** — перетащи `Assets/NAV/ScriptableObjects/Items/Wood.asset`.
    -   **Amount Per Hit** — `1`.

### 9.3. Создать тестовый объект узла в сцене

1.  В Hierarchy: правой кнопкой → **3D Object → Cylinder** (чтобы

3.  Поставь рядом с игроком, например `Position: (0, 1, -3)`.

5.  Add Component → добавь `ResourceNode`

### 9.4. Проверка
