# NAV --- Предметы, ресурсы и крафт (черновик тиров)

## Статус документа

Это **черновик контента**, не финальная спецификация. `PROJECT_STATE.md`
и `GDD_v0.1.md` явно помечают финальный список ресурсов, рецептов и
технологических тиров как **"Not Yet Decided"** — этот файл не отменяет
это, а даёт первую цельную версию, с которой можно работать и которую
можно менять.

Все названия предметов — рабочие (как `Wood`/`Rock`/`StoneAxe` уже в
проекте), не финальный арт-баланс.

Структура тиров вдохновлена Valheim (явно указано в
`GDD_v0.1.md` §7, §12) и подогнана под сеттинг "сказочная Древняя Русь"
(`GDD_v0.1.md` §1, §4) — в частности, название проекта **NAV** прямо
перекликается с славянской **Навью** (потусторонним миром), что
подсказывает тематическую привязку серебра/булата к "нечисти" на
поздних тирах.

## 1. Как устроена тирная система

```
Тир верстака N  →  доступны рецепты с RequiredWorkbenchTier <= N
                 →  открывают инструменты/оружие/броню/постройки тира N
                 →  для рецептов тира N нужны ресурсы тира N
                 →  часть ресурсов тира N требует инструмента тира >= N-1
                    (топор/кирку) чтобы их вообще добыть
```

Это то же соотношение, что уже сейчас в коде: `WorkbenchDefinition.Tier`
+ `RecipeDefinition.RequiredWorkbenchTier` (см. `PlayerCrafting`,
подтверждено в Building/Workbench инкрементах). Ниже — предлагаемое
наполнение по 6 тирам, от дерева до "титана", как просил разработчик.

**Главный инструмент строительства — Молот** (`Hammer`), апгрейдится
вместе с тиром: от деревянного до "небесного" (титанового). Топор и
кирка идут тем же путём как парные добывающие инструменты — без них
тирная система неполная (топором рубят/добывают тир-специфичное дерево
и являются оружием, киркой бьют руду), они явно предполагаются GDD §7
("Axes", "Mining", "Woodcutting" — навыки уже перечислены).

## 3. Крафтовые станции

Помимо самого Верстака, прогрессия по металлам требует отдельных
станций — это стандартный паттерн (Valheim: Kiln, Smelter, Forge) и он
уже согласуется с `GDD_v0.1.md` §12 ("new workbench capability → new
recipes"):

-   **Верстак (`Workbench`)** — уже реализован в коде. Тир пока
    жёстко задан в самом ассете (`WorkbenchDefinition.Tier`), т.е.
    "апгрейд" сейчас технически означает **разместить верстак более
    высокого тира**, а не проапгрейдить существующий на месте. Апгрейд
    "на месте" (как в Valheim — положить рядом Chopping
    Block/Tanning Rack и т.п., и тир вырастет) — это отдельное архитектурное
    решение, которое НЕ принято и не должно молча приниматься при
    реализации (см. `CLAUDE.md` "No Silent Architecture Changes") —
    см. раздел 7 ниже.
-   **Угольная яма (`CharcoalPit`)** — превращает Wood в Уголь
    (`Charcoal`), нужен для Кузницы.
-   **Кузница (`Forge`)** — плавит руду в слитки (`OreDeposit` →
    `MetalBar`) и открывает рецепты металлического оружия/брони/
    инструментов. Как и Верстак, имеет свой тир (Кузница I для
    Бронзы, апгрейдится для Железа/Серебра/Булата/Небесного металла).
-   **Точильный камень (`Grindstone`)** — тир 5+, нужен для булатных
    рецептов (легендарная выделка стали).
-   **Костёр (`Campfire`)** и **Котёл (`Cauldron`)** — станции для еды
    (см. раздел 6), не завязаны на тир оружия/брони напрямую.

Ни одна из этих станций (`Forge`, `CharcoalPit`, `Grindstone`,
`Campfire`, `Cauldron`) пока не реализована в коде — сейчас есть только
`Workbench`. Это ожидаемо: Food/Building/Workbench-прогрессия в
`DEVELOPMENT_ROADMAP_v0.1.md` описаны как отдельные пункты, ещё не
детализированные до конкретных станций.

## 4. Тир 1 — Дерево и Камень *(уже частично реализовано)*

### Ресурсы
-   **Wood** (Дерево) — рубится топором с деревьев. *Уже есть:
    `Wood.asset`, добывается через `TreeWoodNode` (`ResourceNode`).*
-   **Rock** (Камень) — добывается с каменных узлов. *Уже есть:
    `Rock.asset`, добывается через `StoneRockNode`.*
-   **Flint** (Кремень) — россыпи у воды/берега, ранняя альтернатива
    камню для самых первых инструментов (тематически привязан к
    биому Ocean/побережье).
-   **Resin** (Смола) — с деревьев, нужен для факелов/первых
    зажигательных рецептов.

### Инструменты
-   **Деревянный молот** (`Hammer_Wood`) — тир-1 инструмент
    строительства. Крафтится первым, ещё до верстака (как в Valheim:
    молот — это то, чем ты СТАВИШЬ первый верстак).
-   **Каменный топор** (`StoneAxe`) — *уже есть как ассет
    (`StoneAxe.asset`, категория Tool), но пока не даёт игровой
    механики рубки — гейтинг добычи по инструменту явно отложен, см.
    "Deliberately out of scope" в `PROJECT_STATE.md` для Gathering.*
-   **Каменная кирка** (`StonePickaxe`) — аналог топора для руды/камня.

### Оружие
-   **Каменный меч** (`Stone Sword`) — *уже есть как `WeaponDefinition`
    (`StoneSword.asset`): урон 15, дальность 2.5м.*
-   **Деревянная палица** (`Wood Club`) — дешёвая альтернатива мечу,
    тупое оружие (категория Clubs, GDD §7).
-   **Деревянный лук + Каменные стрелы** (`Wood Bow` / `Stone Arrow`) —
    дальний бой, категория Bows (GDD §7).

### Броня
-   **Одежда из шкур** (`Hide Armor`) — тир-1 лёгкая броня. Требует
    `Hide` (шкура) — ресурс с нейтральных/враждебных существ, которых
    пока нет в проекте (Creatures — Phase 8). Пока недоступна для
    крафта, но определение можно завести заранее как placeholder.

### Постройки
-   **Деревянная стена / Деревянный фундамент** — *уже есть
    (`WoodWall.prefab`, `WoodFoundation.prefab`)*.
-   **Деревянная дверь, Деревянная крыша, Деревянный частокол** —
    естественные дополнения того же материала.

## 5. Тиры 2--6 — Металлы

### Тир 2 — Медь / Олово → Бронза

-   **Медная руда** (`CopperOre`) — добывается киркой из медных
    жил, привязанных к новому под-биому (например, "Каменистые
    холмы" внутри Plains/Forest — точное размещение решает мировая
    генерация, вне скоупа этого документа).
-   **Оловянная руда** (`TinOre`) — реже, часто у воды/на островах.
-   **Уголь** (`Charcoal`) — Wood, переработанный в Угольной яме.
-   **Бронзовый слиток** (`BronzeBar`) — Кузница: `CopperOre +
    TinOre + Charcoal → BronzeBar`.
-   Инструменты/оружие/броня: Бронзовый молот, Бронзовый топор,
    Бронзовая кирка, Бронзовый меч/копьё/булава, Бронзовый щит,
    Бронзовая броня (набор).
-   Постройки: усиленные бронзовыми элементами двери/ворота-ловушки.

### Тир 3 — Железо

-   **Железная руда** (`IronOre`) — требует более тёмного/опасного
    биома (болото/пещеры — такого биома пока нет в подтверждённом
    списке GDD §5, "More biomes will be added during production" —
    это прямая причина завести такой биом раньше, чем понадобится
    Тир 3 в реальной прогрессии).
-   **Железный слиток** (`IronBar`) — Кузница (апгрейд): `IronOre +
    Charcoal → IronBar`.
-   Инструменты/оружие/броня: Железный молот/топор/кирка, Железный
    меч/секира/двуручный меч, Железный щит, Кольчуга (`Chainmail`).
-   Постройки: железные петли/укрепления, железные ловушки-капканы.

### Тир 4 — Серебро

-   **Серебряная руда** (`SilverOre`) — горный/холодный биом (тоже
    ещё не в подтверждённом списке биомов), тематически рядом с
    первыми "боссовыми" зонами.
-   **Серебряный слиток** (`SilverBar`).
-   Тематическая роль: серебро в славянском фольклоре и в сеттинге
    **NAV/Навь** — классический материал против нежити/нечисти;
    предлагается дать серебряному оружию бонус урона по
    "нежить"-тегу существ, когда появится тегирование Creatures
    (Phase 8) — это дизайн-предложение, не реализация.
-   Инструменты/оружие/броня: Серебряный молот/топор/кирка,
    Серебряный меч/палица, Серебряный амулет (аксессуар, если/когда
    появится слот аксессуаров).

### Тир 5 — Булат (легендарная сталь)

-   **Булатная сталь** (`BulatSteel`) — `IronBar + Charcoal + редкий
    компонент` (например, "Слеза Сварога"/"Небесная искра" —
    мифологический тримминг, конкретный редкий ингредиент — предмет
    для отдельного обсуждения, не финализирую здесь) на Точильном
    камне + Кузнице.
-   Тематический якорь: "булатный меч" — устойчивый образ русской
    сказки. Тир 5 — естественное место для рецепта легендарного
    **Меча-кладенца** (`Sword_Kladenets`) как топового крафтового
    оружия предбоссового/боссового уровня. Важно: сама механика
    "боссов" в проекте **NOT FINALIZED** (`CLAUDE.md` Boss Rule) —
    здесь Меч-кладенец описан только как тир-5 контент-плейсхолдер,
    без привязки к конкретному боссу/лору.
-   Инструменты/оружие/броня: Булатный молот/топор/кирка, Булатный
    меч (включая Меч-кладенец как уникальный вариант), Булатная броня.

### Тир 6 — Небесный металл ("титан")

-   Разработчик запросил апгрейд молота именно "до титанового" — как
    рабочее название тира механически оставляю **Titanium**, но
    предлагаю лорную обёртку **"Небесное железо"** (метеоритная
    руда, упавшая с неба) — она не противоречит механике (тот же
    тир-6 металл), но звучит уместнее для сказочной Руси, чем
    современный химический элемент. Финальное имя — на усмотрение
    разработчика, оба варианта равноценны механически.
-   **Небесная руда** (`SkymetalOre` / `TitaniumOre`) — не добывается
    обычной киркой в мире; источник — редкие метеоритные точки
    интереса и/или боссовый дроп (согласуется с Boss Rule: "boss
    rewards" — предметы наград, не сами боссы).
-   **Слиток небесного металла** (`SkymetalBar`) — Кузница
    максимального апгрейда.
-   Инструменты/оружие/броня: топовый молот/топор/кирка/меч/броня —
    эндгейм-снаряжение, финальный баланс намеренно не прописываю
    (см. "Final weapons and armor balance" в "Not Yet Decided").

## 6. Еда (кратко)

Отдельная система (GDD подтверждает Food System), тирую её отдельно от
оружия/брони, привязка мягкая (по станции, не по верстаку):

-   **Тир 0 (сырое)**: Ягоды (`Berries`), Грибы (`Mushrooms`), Семена
    (`Seeds`) — собираются в мире, едятся без готовки (слабый эффект).
-   **Тир 1 (Костёр)**: Жареное мясо (`RoastedMeat`), Печёные овощи —
    требует `Campfire`.
-   **Тир 2+ (Котёл)**: Похлёбки/варёные блюда (`Stew`) — требует
    `Cauldron`, комбинирует несколько ингредиентов, более сильный и
    долгий эффект (сытость/реген здоровья/стамины — конкретные
    формулы вне скоупа этого документа).
-   Огороды/фермерство (`Farming`, уже упомянуто в GDD §7 как навык)
    дают Тир 1--2 ингредиенты (морковь, репа, пшеница — классические
    для Руси).

## 7. Что уже есть в коде vs. что нужно спроектировать отдельно

Чтобы не создавать иллюзию, что всё из этого документа уже работает:

**Уже реализовано:**
-   `ItemDefinition`/`ItemCategory` (Resource/Tool/Weapon/Armor/Food/
    Building/Misc) — категории покрывают всё перечисленное выше.
-   `Wood.asset`, `Rock.asset`, `StoneAxe.asset` (без игровой механики
    рубки/добычи по инструменту), `StoneSword.asset` (`WeaponDefinition`).
-   `WorkbenchDefinition`/`Workbench` (один тир на объект, гейтит
    `RecipeDefinition.RequiredWorkbenchTier`).
-   `RecipeDefinition`/`PlayerCrafting` — сам механизм крафта (список
    ингредиент+количество → результат) уже общий и не требует
    переделки под новые тиры/предметы, только новый контент
    (ассеты).

**Требует отдельного архитектурного решения ДО реализации** (по
`CLAUDE.md` "No Silent Architecture Changes" — не будет сделано молча):
1.  **Апгрейд верстака "на месте"** — сейчас `Workbench.Tier`
    неизменяем после `Configure`/`Awake`, апгрейд = замена объекта в
    мире. Нужно решить: разные префабы по тирам (просто), или runtime
    апгрейд одного объекта (как в Valheim, сложнее).
2.  **Гейтинг добычи по инструменту** — `ResourceNode.Interact()`
    сейчас не проверяет, чем бьёт игрок (см. явный "Deliberately out
    of scope" в `PROJECT_STATE.md`). Тирные руды (медь/железо/серебро/
    небесный металл) по дизайну должны требовать кирку минимум N-1
    тира — это новая логика, не только новый контент.
3.  **Новые станции** (`Forge`, `CharcoalPit`, `Grindstone`,
    `Campfire`, `Cauldron`) — ни одна не реализована; вероятно,
    большинство сможет переиспользовать паттерн `Workbench` (триггер-
    зона + свой тир + гейтинг рецептов), но это нужно подтвердить по
    каждой отдельно, не молча копировать.
4.  **Новые биомы** для руд Тир 3+ (болото/горы) — сейчас
    подтверждённый список биомов в GDD §5 их не включает.
5.  **Источник `Hide`/мяса** — привязан к Creatures (Phase 8),
    которых ещё нет.

Этот документ — контентная основа для последующих инкрементов (по
аналогии с тем, как Gathering/Crafting/Workbench уже добавлялись
пошагово): реализация должна по-прежнему идти маленькими
подтверждаемыми шагами, а не одним большим "накатить все тиры сразу".
