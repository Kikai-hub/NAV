# NAV Project Documentation v0.1

This package contains the initial design and Claude Code development
documents for NAV.

Important: - Bosses are intentionally NOT finalized. - The full game is
expected to have 7--10 bosses. - Claude must use placeholder/test bosses
only until boss design is explicitly requested. - MVP is
single-player. - Long-term multiplayer target is 1--4 player co-op.

Files: - GDD_v0.1.md --- Game Design Document - CLAUDE.md --- persistent
development rules for Claude Code - PROJECT_STATE.md --- project
memory/state - ARCHITECTURE_v0.1.md --- technical architecture -
DEVELOPMENT_ROADMAP_v0.1.md --- phased development plan -
CLAUDE_MASTER_PROMPT.md --- initial master instruction for Claude Code
